# Sucheendra Student Site

AstroPaper-based starter website for a student portfolio and blog.

## Run locally

```bash
npm install
npm run dev
```

## Edit your data

- `astro-paper.config.ts` — site title, description, socials, and links
- `src/content/pages/about.md` — your bio and student details
- `src/content/posts/` — your posts, notes, and project updates

## Build

```bash
npm run build
```
